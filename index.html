Full source is on GitHub: https://github.com/felixmelanson/pkr_anim

Plain JavaScript and a 2D canvas, no framework or build step. Every frame is drawn from code: the cells are procedural shapes with a clay shading pass and a glowing edge texture. The site plays those frames as 4K video, rendered from the same code with tools/render-test.mjs; add ?live=1 to the URL to draw them live in your browser instead.

Scenes live in js/scenes/steps.js, the figure data in js/data.js. Data are redrawn from Lourenco et al., 2013 (Cell Metabolism); see References.
